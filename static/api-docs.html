BotAI API Docs

Các endpoint ổn định để tích hợp chatbot vào hệ thống khác.

GET /api/v1/health

Kiểm tra trạng thái model, vector index, BM25 và số chunk đã index.

GET /api/v1/bots

Lấy danh sách bot đang bật.

GET /api/v1/documents?bot_id=1

Lấy danh sách tài liệu đã ingest. Tham số bot_id là tùy chọn.

POST /api/v1/chat

Gửi câu hỏi và nhận JSON có cấu trúc, phù hợp cho website/app khác.

{
  "message": "Câu hỏi của người dùng",
  "session_id": "external-session-001",
  "bot_id": 1,
  "include_raw_response": true
}

Response có cấu trúc:

{
  "ok": true,
  "answer": "Nội dung trả lời được sinh từ tài liệu truy xuất",
  "sources": [
    {
      "document": "ten-tai-lieu.pdf",
      "page": "trang hoặc khoảng trang",
      "url": "/documents/ten-tai-lieu.pdf#page=1",
      "type": "loại nguồn",
      "excerpt": "trích đoạn liên quan",
      "raw": "..."
    }
  ],
  "session_id": "external-session-001",
  "bot_id": 1,
  "has_sources": true,
  "raw_response": "..."
}

Endpoint này dùng cùng pipeline RAG, cache, ghi lịch sử và chống hallucination như giao diện chat hiện tại.
